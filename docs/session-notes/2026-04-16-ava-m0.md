## Décisions prises

- **TTS backend default = Kokoro-82M** `ff_siwis` (validé POC 2026-04-16 avant M0)
- **Python 3.12** (OpenJarvis supporte 3.10–3.13)
- **Wazuh agent ID 011** (010 pris par pve-02 éteint intentionnellement)
- **Workaround /tmp noexec CIS** : `TMPDIR=/home/avalon/ava/.tmp-exec` via .env (phonemizer espeak-ng copie sa lib en temp)
- **Authentification git via HTTPS + .netrc** (pas SSH) : le port 22 sortant WAN est bloqué par le firewall Avalon, et le conteneur GitLab a un cache clé SSH capricieux
- **GitLab SSL verify disabled** pour `gitlab.avalon-network.com:8443` (Cloudflare Origin cert pas dans CA bundle de la VM)
- **CPU type VM = host** (pas `kvm64` par défaut) : requis pour les extensions AVX/AVX2 demandées par PyTorch/Kokoro

## Problèmes rencontrés et résolution

| # | Problème | Résolution |
|---|----------|------------|
| 1 | Template Proxmox 9000 absent | Créé depuis Debian 13 cloud image (image qcow2 + qm create + cloud-init + template) |
| 2 | Clé SSH `avalon@ava` dans `roles/proxmox/defaults` obsolète (ne match plus la clé actuelle) | Mis à jour defaults/main.yml avec la bonne clé |
| 3 | Host key stale dans `~/.ssh/known_hosts` sur AVA après rebuild | `ssh-keygen -R 192.168.100.15` après chaque rebuild |
| 4 | `common_packages: chrony` introuvable au premier run Ansible | Bug cache Nexus : `cache_valid_time: 3600` skip update → enlevé dans roles/common |
| 5 | Site.yml failed sur apt update Nexus (ConnectionTimeout 8089) | nftables bastion profile n'autorisait pas port 8089 sortant → règles ajoutées dans host_vars |
| 6 | Site.yml failed sur node_exporter service introuvable | Bug `set_fact` ordre : fact évalué avant install APT → ajout override après install dans roles/monitoring |
| 7 | Teleport install échoue (pas de keyring) | Keyring bootstrappé manuellement via `curl apt.releases.teleport.dev/gpg` puis rôle passe |
| 8 | Wazuh agent install skip (rôle défensif) | Install manuel via `WAZUH_MANAGER=192.168.100.5 apt install wazuh-agent` puis rôle configure |
| 9 | Fork GitHub public → privé impossible | Limitation GitHub : fork public ne peut pas être rendu privé. Laissé public (contenu OpenJarvis déjà public ; secrets dans SOPS + .env gitignored) |
| 10 | Token GitHub n'a pas scope `delete_repo` ni `admin:public_key` | Utilisé deploy key repo-scoped à la place |
| 11 | Git push GitLab SSH permission denied malgré clé ajoutée | Bascule vers HTTPS + .netrc avec token |
| 12 | Git push GitLab 8443 timeout | nftables bastion profile n'autorise pas 8443 sortant → règle ajoutée dans host_vars |
| 13 | GitLab TLS verify fail | Cloudflare Origin cert pas trusté ; `git config http.url.sslVerify false` |
| 14 | CLAUDE.md dans .gitignore upstream | `git add -f CLAUDE.md` |
| 15 | PyTorch `RuntimeError: could not create a primitive` | CPU type `kvm64` par défaut masque AVX → `qm set 107 --cpu host` + reboot |
